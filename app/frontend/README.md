# 🦷 Orthodontic Surgeon - Frontend Client

This directory contains the React 19 single-page application (SPA) built with Vite, Tailwind CSS, and Lucide React.

For full project documentation, architecture, API endpoints, and deployment details, please refer to the [Root README.md](../../README.md).

## 🚀 Quick Start (Frontend)

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build
```

## 🛠 Key Libraries & Tools
- **React 19** & **Vite 7**
- **Tailwind CSS** (Medical Clean design system)
- **Lucide React** (Icons)
- **Sonner** (Toast notifications)
- **React Router v7** (Client-side routing)
- **Axios** (API communication)
